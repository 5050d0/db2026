\section{Бизнес правила}
\subsection*{Е1. Пользователь хранилища}
\begin{enumerate}
  \item Пользователь обязан иметь одну назначенную роль, принадлежащую множеству ролей.
\end{enumerate}
\subsection*{Е2. Роль пользователя}
\begin{enumerate}
  \setcounter{enumi}{1}
  \item Значение роли может принимать только значения "пользователь", "автор", "модератор".
\end{enumerate}
\subsection*{Е3. Документ}
\begin{enumerate}
\setcounter{enumi}{2}
\item Основной автор документа должен принадлежать множеству пользователей.
\item Статус документа может принимать только значения "отклонен", "отправлен на доработку", "готов к публикации".
\item Документ должен быть связан хотя бы с одной тематикой из множества тематик.
\end{enumerate}

\subsection*{Е4. Избранное}
\begin{enumerate}
\setcounter{enumi}{5}
\item Пользователь и документ должны принадлежать соответствующим множествам.
\end{enumerate}

\subsection*{Е5. Информатор}
\begin{enumerate}
\setcounter{enumi}{6}
\item Идентификатор информатора должен быть уникальным, не пустым значением.
\end{enumerate}

\subsection*{Е6. История просмотров}
\begin{enumerate}
\setcounter{enumi}{7}
\item Пользователь и документ должны принадлежать соответствующим множествам.
\item Записи истории просмотров не должны удаляться или изменяться.
\end{enumerate}

\subsection*{Е7. Тематика документов}
\begin{enumerate}
\setcounter{enumi}{9}
\item Если родительская тематика существует, она должна принадлежать множеству тематик.
\end{enumerate}

\subsection*{Е8. Безопасные IP-адреса}
\begin{enumerate}
\setcounter{enumi}{10}
\item Пользователь должен принадлежать множеству пользователей.
\item Пользователь должен иметь роли "пользователь" или "автор".
\item Количество безопасных IP-адресов для каждого пользователя не должно превышать 3.
\end{enumerate}

\subsection*{Е9. История входов по IP}
\begin{enumerate}
\setcounter{enumi}{13}
\item Пользователь должен принадлежать множеству пользователей.
\item Записи истории входов не подлежат изменению и удалению.
\end{enumerate}

\subsection*{Е10. Блокировки пользователей}
\begin{enumerate}
\setcounter{enumi}{15}
\item Пользователь, ответственный администратор/модератор должны принадлежать множеству пользователей.
\item Тип операции может принимать только значения "блокировка", "разблокировка".
\item Снять блокировку (разблокировать) может только пользователь с ролью "модератор".
\item Записи о блокировках и разблокировках не должны удаляться.
\end{enumerate}

\subsection*{Е11. Комментарий}
\begin{enumerate}
\setcounter{enumi}{19}
\item Автор и документ должны принадлежать соответствующим множествам сущностей.
\item Если существует, родительский комментарий должен принадлежать множеству комментариев к данному документу.
\item Если существует, обращение к пользователю должно принадлежать множеству пользователей.
\end{enumerate}
