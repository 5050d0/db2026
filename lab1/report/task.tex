\section{Содержание работы}

\textbf{Студент должен}\par
\begin{enumerate}
  \item Проанализировать текст варианта.
  \item Выделить основные сущности предметной области.
  \item Сформулировать бизнес-правила и ограничения.
  \item Определить связи между сущностями и их кратность.

\end{enumerate}

\textbf{Отчетные материалы}\par
\begin{enumerate}
  \item Список выделенных сущностей.
  \item Нумерованный список бизнес-правил.
  \item Матрица связей сущностей с указанием кратности.
\end{enumerate}
